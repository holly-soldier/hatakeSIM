# 【非公式】畑シミュレーター

ブラウザ上で動作する、2Dグリッドベースの畑レイアウトシミュレーターです。

## 主な機能

* **アイテム配置**: スプリンクラー（強・普・小）、果樹、水田、建物（鶏小屋、家畜小屋、馬小屋）、テキストなどの配置。
* **建物の回転**: 建物などの一部アイテムは、選択した状態で再タップすると縦向き・横向きが切り替わります。
* **カスタム色追加**: 自由な名称と色のアイテムを自作してパレットに追加可能。
* **範囲選択と一括処理**: 範囲を指定して、水田やカスタム色での塗りつぶし、または一括削除が可能。
* **移動と削除**: 配置済みのアイテムをドラッグして移動させたり、消しゴムツールで削除できます。
* **取り消し (Undo)**: 直前の操作を50段階まで取り消し可能。
* **保存と復元**:
  * ローカルストレージによる自動保存機能。
  * JSONファイルとして設定を含めたバックアップ（エクスポート）と復元（インポート）。
* **アイテム集計**: 配置しているスプリンクラーや建物の数を自動でカウントします（現在の畑、または全体で切り替え可能）。
* **マップ操作**: 1本指でドラッグ連続配置、2本指でパン（移動）およびピンチイン・アウト（ズーム）。

## 使い方

1. 構成ファイル（`index_v10.html`など）をWebブラウザで開きます。
2. 画面下部のパレットから配置したいアイテムを選択します。
3. 画面上のグリッドをタップ、またはドラッグして配置します。
4. 画面右上の「⚙️ 設定」から、バックアップデータの書き出しや読み込みが行えます。

## 動作環境
PCおよびスマートフォンのモダンブラウザ（Chrome、Safari、Edgeなど）。タッチ操作に最適化されています。

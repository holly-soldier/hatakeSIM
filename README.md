# 【非公式】畑シミュレーター

ブラウザ上で動作する、畑のレイアウトを検討・シミュレーションするための非公式Webアプリケーションです。
スマートフォンやタブレットでのタッチ操作に最適化されており、PWA（Progressive Web App）としてホーム画面に追加してアプリのように利用することも可能です。

## 主な機能

* **3つの畑データを保存可能**
  * 「1個目」「2個目」「3個目」のタブを切り替えて、別々のレイアウトを作成・保存できます。
  * 畑を切り替えた際、ズームや表示位置は自動的に全体が見渡せるサイズにリセットされます。
* **多彩なアイテム配置**
  * **スプリンクラー**（強化: 7x7、普通: 5x5、小: 3x3）
  * **果樹**（周囲1マス）
  * **水田**（土手生成）
  * **建物**（鶏小屋、家畜小屋、馬小屋）
* **建物の回転と視覚的な向き表示**
  * 選択中の建物アイコンをもう一度タップすることで、縦向き・横向きを回転させることができます。
  * 建物の向きが一目でわかるよう、横長の場合は**赤文字（横 〇×〇）**、縦長の場合は**青文字（縦 〇×〇）**でパレットに表示されます。
* **配置アイテム集計機能（現在・全体切替）**
  * 配置されているスプリンクラーや動物小屋などの数を自動集計し、画面下部に一覧表示します。
  * 「切替」ボタンを押すことで、「現在の畑」の集計と、3つの畑すべてを合算した「畑全体」の集計を瞬時に切り替えることができます。
* **オートセーブ機能**
  * 配置や削除を行うたびに、ブラウザのローカルストレージへ自動的に保存されます。
* **アンドゥ（元に戻す）**
  * 操作を間違えた際、「戻る」ボタンで前の状態に復元できます（最大50手まで記憶）。
* **バックアップと復元（JSON）**
  * 「設定」メニューから、現在の全データをJSONファイルとしてダウンロード（バックアップ）できます。
  * ダウンロードしたファイルを読み込ませることで、別端末やブラウザにデータを移行・復元できます。
* **くっきりとしたズーム表示**
  * 拡大してもぼやけないピクセルパーフェクトな描画（`image-rendering: pixelated`）を採用し、ドット絵のようにくっきりと確認できます。

## 操作方法

1. **画面の移動・拡大縮小**
   * 2本指で画面をスワイプ（移動）またはピンチイン・ピンチアウト（拡大縮小）します。
2. **アイテムの配置**
   * パレットから配置したいアイテムを選択し、マップ上でタップまたは1本指でドラッグします。
3. **アイテムの削除**
   * パレットから「消しゴム」を選択し、削除したいアイテムをタップまたはドラッグでなぞります。
4. **一括リセット**
   * パレット右端の「リセット」ボタンを押すと、現在開いている畑のアイテムをすべて消去します。

## 動作環境

* iOS (Safari)
* Android (Chrome)
* Windows / Mac の各種モダンブラウザ (Chrome, Edge, Safari, Firefoxなど)

## 開発・カスタマイズについて

本アプリは単一の `index.html` ファイルで構成されています。
今後のアップデートや修正を行う際は、ファイルのバージョン表記 `<span class="version">vYY.MM.DD.HHMM</span>` を現在時刻に合わせて更新してください。

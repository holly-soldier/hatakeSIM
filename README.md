# ほの暮らしの庭 畑シミュレーター (HonoFarm Simulator)

『ほの暮らしの庭』の畑のレイアウトをブラウザ上でシミュレーションできるWebアプリケーションです。スプリンクラーの水やり範囲や、建物の配置、果樹・水田のエリア計算などを視覚的に確認しながら、自分だけの最適な農場レイアウトを考えることができます。

## ✨ 主な機能

* **3つの畑サイズに対応**
  * 1個目の畑 (20×25) ※右下の自宅スペース(7×9)考慮済み
  * 2個目の畑 (29×27)
  * 3個目の畑 (32×25)
* **ドラッグ＆ドロップ配置**
  * アイテム（スプリンクラー、果樹、水田、鶏小屋、家畜小屋）を直感的にドラッグして配置可能。
* **水やり範囲・影響エリアの可視化**
  * スプリンクラー（強化: 7×7, 通常: 5×5, 小: 3×3）の散水範囲を半透明の青色でハイライト。
  * 果樹の周囲(3×3)や、水田周囲の土手も自動計算して表示。
* **建物サイズの正確なブロック**
  * 鶏小屋(6×7)、家畜小屋(10×14)のサイズを再現し、クリック（タップ）で縦横の回転・反転が可能。
* **スマホ・タブレット対応のタッチ操作**
  * 1本指：アイテムのドラッグ配置・移動
  * 2本指：マップのピンチイン/アウト（拡大・縮小）、スワイプ移動
* **PWA（Progressive Web App）対応**
  * スマホの「ホーム画面に追加」からインストールすることで、ネイティブアプリのようにフルスクリーンでオフライン動作可能。アップデートもバックグラウンドで自動反映されます。

## 📱 使い方（ユーザー向け）

1. **アクセス:** GitHub Pages等で公開されたURLにスマホまたはPCのブラウザからアクセスします。
2. **アイテムの選択:** 画面上部のパレットから配置したいアイテムをタップします（建物の場合はもう一度タップすると縦横が反転します）。
3. **配置:** マップ上の任意の場所を指でなぞる（ドラッグする）と、配置のプレビューと影響範囲が表示されます。指を離すと確定して配置されます。
4. **マップの操作:** 2本指で画面をなぞるとマップの移動、広げたり狭めたりするとズームができます。
5. **削除:** パレットから「消しゴム」を選び、消したいアイテムをタップすると削除できます。

## 🛠 導入手順（開発者向け・GitHub Pagesでの公開方法）

このリポジトリをフォークまたはクローンし、ご自身のGitHub環境にアップロードしてください。

1. `index.html`, `manifest.json`, `sw.js` を同じディレクトリに配置します。
2. GitHubのリポジトリの **Settings > Pages** を開きます。
3. `Branch` を `main` (または公開したいブランチ) に設定し、`Save` を押します。
4. 数分待つと `https://<あなたのユーザー名>.github.io/<リポジトリ名>/` のURLが発行されます。

## 🔄 アップデートの仕組み (Service Worker)

アプリのコード（HTML等）を更新してGitHubにプッシュすると、ユーザーが次回アプリを開いた際に裏側で新しいファイルがキャッシュされます。
**もう一度アプリを再起動（タスクキルして開き直すなど）**すると、最新のバージョンが適用されます。
※確実にキャッシュを更新させたい場合は、`sw.js` 内の `CACHE_NAME` のバージョン番号（例: `hono-farm-v26-10-22`）をインクリメントしてください。
